# 4.2寸 RLCD (ST7305) 与 ESP32-S3-Nano 硬件开发技术规范

## 1. 硬件规格与概述

- **屏幕尺寸**：4.2 英寸反射式记忆液晶屏（RLCD / 反射式黑白液晶）
- **物理分辨率**：$400 \times 300$ 像素   
- **驱动控制器**：Sitronix ST7305   
- **触控面板**：电容式多点/单点触摸（I2C 接口，排线 Pin 15~19）   
- **FPC 排线接口**：21 Pin，0.3mm 间距 下接/双面接触   
- **主控平台**：ESP32-S3-Nano（Arduino / ESP-IDF 架构）

## 3. 电气规范与外围要求

1. **去耦电容（必加）**：
   - 在转接板的 **3.3V (Pin 5/6)** 与 **GND (Pin 1/4)** 之间就近并联一颗 **$0.1\mu\text{F}\sim 1\mu\text{F}$（耐压 $\ge 10\text{V}$）** 瓷片/贴片电容。   
   - *原因*：ST7305 内部会通过电荷泵将 3.3V 升压至 VGH (+15V) 与 VGL (-10V)，开启瞬态峰值电流较大，去耦电容可避免 ESP32 供电轨被瞬间拉塌导致死机。   
2. **I2C 上拉**：
   - 触摸屏 I2C 速率建议设置为 `100kHz` 或 `400kHz`。若模组内部未集成上拉电阻，需在 SDA (GPIO 7) 和 SCL (GPIO 6) 外挂 $4.7\text{k}\Omega$ 电阻上拉到 3.3V。

## 4. 控制器 (ST7305) 显存架构与寻址算法 (开发核心)

RLCD 显存映射与普通 TFT 屏幕（如 ST7789）存在本质区别，Trae 在移植和编写驱动时必须遵循以下算法：

### 4.1 窗口与坐标映射参数

- **列地址窗口 (CASET - 0x2A)**：
  - 起始列：`0x0D` (13)
  - 结束列：`0x2E` (46)
  - 有效列数：$46 - 13 + 1 = 34$ 列。
  - **水平像素与列映射关系**：每 1 个列地址控制 **12 个水平像素**。
- **行地址窗口 (RASET - 0x2B)**：
  - 起始行：`0x00` (0)
  - 结束行：`0xCB` (203)
  - 有效行数：204 行。
  - **垂直行交错（2-line interlace）**：面板采用双行交错扫描模式（寄存器 `0xB8: 0x29`），每个 SRAM 行映射物理上的相邻 2 行像素（第 $2N$ 行与第 $2N+1$ 行）。

### 4.2 显存写入格式 (Data Format 0x3A: 0x10)

- 在 $0\text{x}10$ 格式下，每次向显存连续写入 **4 个字节（32-bit）**，实际解码为 **24 个有效单色像素**。

- 全屏单次全刷数据量计算：

  $$\text{全屏字节数} = 34 \,(\text{列}) \times 204 \,(\text{行}) \times 4 \,(\text{字节}) = 27,744 \text{ 字节} \approx 27.1\text{ KB}$$

- 颜色定义：

  - 字节全写 `0x00`：全黑
  - 字节全写 `0xFF`：全白

## 5. 驱动避坑与开发关键点（Trae 规则）

1. **SPI API 选用规范（防缓冲区被覆盖）**：

   - 严禁在批量刷屏时使用 Arduino 的 `SPI.transfer(buffer, len)`，因为该函数为全双工收发，会将未接 MISO 产生的浮空输入覆盖到本地发送缓冲区。
   - **必须使用**单向写接口：`SPI.writeBytes(buffer, len)`，或使用 ESP32 硬件 DMA 发送（`spi_device_polling_transmit` / `spi_device_queue_trans`）。

2. **片选引脚冲突避坑**：

   - 调用 `SPI.begin(SCK, MISO, MOSI, SS)` 时，第四个参数 `SS` 请显式传入 `-1`：

     C++

     ```
     SPI.begin(PIN_LCD_SCK, -1, PIN_LCD_MOSI, -1);
     ```

   - 必须在软件层手动控制 CS（`digitalWrite(PIN_LCD_CS, LOW/HIGH)`），防止硬件外设占用控制权导致命令/数据帧丢失。

3. **刷新速率与功耗模式**：

   - 处于低功耗模式（LPM，`0x39`）时，芯片扫描帧率仅 1Hz 左右，刷新会出现百叶窗式滚动痕迹。
   - 日常动态刷新建议保持在高性能模式（HPM，`0x38`），并将帧率寄存器 `0xB2` 设为 $16\text{Hz}\sim 32\text{Hz}$。
   - SPI 时钟频率建议：飞线调试推荐 **$8\text{MHz}\sim 12\text{MHz}$**；PCB 紧凑布线后可提至 **$20\text{MHz}\sim 24\text{MHz}$**。

4. **触摸适配参考**：

   - 参考 `docs/ESP32-S3-RLCD-BBK` 源码中的 I2C 设备探测代码，触摸 IC 常见 I2C 地址为 `0x38`（FT 系列）或 `0x15`（CST 系列）。可以先在 `setup()` 中运行一次标准 I2C Scanner 确定挂载地址。

## 6. 音频板（ES7210 + ES8311 + NS4150B）引脚映射

### 6.1 排针定义

音频板为 10Pin 2.54mm 排针，丝印从左到右：`GND VCC EN SDA SCL MCK BCK DO WS DI`，**最左侧 GND 为 1 脚**。

原理图（`7210-SC..V1.pdf`）网络名与丝印的对应关系：

| 板上丝印 | 原理图网络名 | 说明 |
| :--- | :--- | :--- |
| EN | PA_EN | 功放使能，经 R10(10k) 接 NS4150B CTRL，另有 R11/R12(100k) 分压到 AU_GND |
| SDA | ES_I2C_SDA | 经 BSS138 隔离，板载 R1(2.2k) 上拉到 AU_3V3（MOS 漏极侧） |
| SCL | ES_I2C_SCL | 经 BSS138 隔离，板载 R2(2.2k) 上拉到 AU_3V3（MOS 漏极侧） |
| MCK | I2S_MCK | ESP32 主出，ES7210 与 ES8311 共用 |
| BCK | I2S_BCK | 位时钟 |
| DO | I2S_DO | ESP32 → ES8311 DSDIN |
| WS | I2S_WS | 声道选择（单声道） |
| DI | I2S_DI | ES7210 SDOUT1/TDMOUT → ESP32 |

### 6.2 与 ESP32-S3-Nano 接线表

把音频板 GND 一侧朝向 Nano 的 GND / 5V 端，从该端开始逐位对齐（信号顺序单调递增，**零交叉**）：

| H1 | 丝印 | Nano 丝印（下排第几位） | 物理 GPIO | 功能 | 线径 |
| :---: | :--- | :--- | :--- | :--- | :---: |
| 1 | GND | GND（第 1 位） | GND | 主接地点 | **26AWG** |
| 2 | VCC | 5V（第 2 位） | 5V | 板载 XC6206 需压差，**不可接 3V3** | **26AWG** |
| 3 | EN | 48（第 4 位） | GPIO 48 | PA_EN，高电平开功放 | 32AWG |
| 4 | SDA | 47（第 5 位） | GPIO 47 | 独立 I2C，主控侧需 2.2k 上拉 | 32AWG |
| 5 | SCL | 38（第 6 位） | GPIO 38 | 独立 I2C，主控侧需 2.2k 上拉 | 32AWG |
| 6 | MCK | 21（第 9 位） | GPIO 21 | 主时钟输出 | 32AWG |
| 7 | BCK | 18（第 11 位） | GPIO 18 | 位时钟 | 32AWG |
| 8 | DO | 17（第 12 位） | GPIO 17 | ESP32 → ES8311 | 32AWG |
| 9 | WS | 16（第 13 位） | GPIO 16 | 声道选择 | 32AWG |
| 10 | DI | 15（第 14 位） | GPIO 15 | ES7210 → ESP32 | 32AWG |

下排空置：第 3 位（BOOT / GPIO 0）、第 7 位（GPIO 39）、第 8 位（GPIO 40）、第 10 位（GND，备用回流地）、第 15~18 位（GPIO 41/42/45/46，禁用）。

### 6.3 关键电气要求

1. **I2C 上拉**：400kHz 下主控侧必须外挂 **2.2kΩ** 到 3V3。内部约 45kΩ 上拉的 RC ≈ 4.5µs，远超 Fast Mode 要求的 300ns 上升沿；4.7kΩ 在总线电容约 110pF 时约 438ns，同样超标。音频板 R1/R2(2.2k) 位于 BSS138 漏极侧，**不能替代**主控侧上拉。
2. **总线隔离**：SCL(GPIO 38) 与 MCK(GPIO 21) 之间空出 GPIO 39/40 两个孔位（≈5.08mm），这是下排可用脚位下能做到的最佳隔离。
3. **时钟回流**：MCK(GPIO 21) 与 BCK(GPIO 18) 之间正好隔着下排第 10 位 GND，可将该脚用 32AWG 引到 H1-1 作为时钟回流地。
4. **单点接地**：H1-1 只引一根 26AWG 到 Nano 下排第 1 位 GND。如需第二条回流地，必须同样回到 H1-1 焊盘，**不得另找接地点**，否则形成地环。
5. **线缆走法**：5V 与 GND 均 26AWG 并**绞合**；信号线 32AWG 足够（信号电流 µA 级，换粗只增加焊点应力）；I2C 两线**并排不绞**，可加一根 32AWG 地线夹中间（两端都接才有效）。
6. **功放供电**：NS4150B 满功率峰值接近 1A，USB 供电不足时会掉压复位，此时需给音频板单独供 5V 并与 Nano 共地。

### 6.4 与代码的对应关系

`main/boards/luobo/esp32-s3-nano-rlcd/config.h`：

```c
#define AUDIO_I2S_GPIO_MCLK GPIO_NUM_21
#define AUDIO_I2S_GPIO_BCLK GPIO_NUM_18
#define AUDIO_I2S_GPIO_WS   GPIO_NUM_16
#define AUDIO_I2S_GPIO_DIN  GPIO_NUM_15
#define AUDIO_I2S_GPIO_DOUT GPIO_NUM_17
#define AUDIO_CODEC_PA_PIN       GPIO_NUM_48
#define AUDIO_CODEC_I2C_SDA_PIN  GPIO_NUM_47
#define AUDIO_CODEC_I2C_SCL_PIN  GPIO_NUM_38
```

触摸与 codec 使用**两条独立 I2C 总线**：触摸 `I2C_NUM_0`（SCL 6 / SDA 7），codec `I2C_NUM_1`（SCL 38 / SDA 47），避免触摸轮询流量顺着音频排线进入模拟前端。
